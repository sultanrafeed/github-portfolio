# Collecting notes and visits into a spreadsheet

The site is static and hosted on GitHub Pages, so it has no server of its own.
Both the note form and the visit record post to a **Google Apps Script web app**,
which appends rows to a **Google Sheet** you own. The sheet exports to `.xlsx`
whenever you want it in Excel.

No third-party form service, no analytics account, no monthly limit worth
worrying about, and the data sits in your own Drive rather than someone else's
database.

**Time: about ten minutes, once.**

---

## What gets collected

Two separate things land in two tabs of the same spreadsheet.

### Tab `notes`, only when someone presses send

| Column | Source |
|---|---|
| `received_at` | timestamp generated by the script |
| `submitted_at` | timestamp generated in the browser |
| `score` | the 1 to 6 rating, if they gave one |
| `name`, `email`, `role`, `message` | whatever they typed, all optional |
| `page` | which path they submitted from |

### Tab `visits`, automatically, one row per visit

| Column | Source |
|---|---|
| `arrived_at` | when the page loaded |
| `session_id` | random, lives in `sessionStorage`, dies with the tab |
| `country`, `region`, `city` | resolved from IP **inside the visitor's browser**, see below |
| `referrer` | where they came from, or `direct` |
| `landing` | which path they landed on |
| `language`, `timezone` | browser settings |
| `device`, `browser`, `os` | coarse buckets, not a fingerprint |
| `screen`, `viewport` | dimensions |
| `theme` | light or dark |
| `seconds` | visible time on the page |
| `scroll_pct` | how far down they got |
| `sections` | which sections they actually stopped on |
| `actions` | whether they opened the CV, GitHub, a paper, email |

The last four arrive when the visitor leaves the tab, and are written back onto
the same row.

**The IP address is never stored and never sent to the sheet.** The browser asks
`ipwho.is` to turn its own address into a city, keeps the city, and discards the
rest. Your spreadsheet sees "Sydney, New South Wales, Australia" and nothing that
points at a person.

There are no cookies. There is no third-party analytics, no ad network, and no
cross-site tracking.

### Built-in limits

- It honours **Do Not Track** and **Global Privacy Control** automatically, so a
  visitor who has set either is never recorded.
- It can be switched off per browser with
  `localStorage.setItem('noTrack','1')` in the console. There is no visible
  control for this, by choice.
- It stores no IP, sets no cookie, and joins to nothing else.

There is no visible disclosure on the page. That is a normal choice and most
sites make it, but it does mean the page must not claim the opposite: the
colophon says only "no third-party trackers and no advertising", which stays
true. If you ever add a third-party analytics script, cookies or persistent
identifiers, revisit that line and add a consent banner.

### A note on law

Coarse location and device data collected without consent is low-risk but not
zero-risk under GDPR if EU visitors arrive; as an individual you are well under
the threshold of the Australian Privacy Act. The current design (no IP, no
cookie, honoured opt-out signals, nothing joined to anything else) keeps what is
collected minimal, which is the part that matters most. If you ever add cookies, persistent identifiers or a
third-party analytics script, you need a consent banner as well.

## Step 1: create the sheet

1. Go to <https://sheets.google.com> and create a blank spreadsheet.
2. Name it something like `portfolio-data`.
3. Leave it empty. The script creates its own `notes` and `visits` tabs, with
   headers, the first time each one is used.

## Step 2: add the script

1. In that sheet, open **Extensions → Apps Script**.
2. Delete whatever is in `Code.gs` and paste this in full:

```javascript
/**
 * Portfolio backend: notes from the form, plus one row per visit.
 * Deploy as: Execute as = Me, Who has access = Anyone.
 */
const NOTE_HEADERS = ['received_at', 'submitted_at', 'score', 'name', 'email', 'role', 'message', 'page'];
const VISIT_HEADERS = ['arrived_at', 'session_id', 'country', 'region', 'city', 'referrer',
  'landing', 'language', 'timezone', 'device', 'browser', 'os', 'screen', 'viewport',
  'theme', 'seconds', 'scroll_pct', 'sections', 'actions'];

function doPost(e) {
  const lock = LockService.getScriptLock();
  lock.waitLock(20000);
  try {
    const d = JSON.parse(e.postData.contents);
    if (d.type === 'visit') { recordVisit(d); }
    else if (d.type === 'engagement') { updateVisit(d); }
    else { recordNote(d); }
    return json({ ok: true });
  } catch (err) {
    return json({ ok: false, error: String(err) });
  } finally {
    lock.releaseLock();
  }
}

function doGet() { return json({ ok: true, note: 'This endpoint accepts POST only.' }); }

function json(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

function clip(v) { return String(v == null ? '' : v).slice(0, 5000); }

/** Get a tab by name, creating it with headers the first time. */
function tab(name, headers) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sh = ss.getSheetByName(name);
  if (!sh) sh = ss.insertSheet(name);
  if (sh.getLastRow() === 0) {
    sh.appendRow(headers);
    sh.getRange(1, 1, 1, headers.length).setFontWeight('bold');
    sh.setFrozenRows(1);
  }
  return sh;
}

function recordNote(d) {
  tab('notes', NOTE_HEADERS).appendRow([
    new Date(), clip(d.submitted_at), clip(d.score), clip(d.name),
    clip(d.email), clip(d.role), clip(d.message), clip(d.page)
  ]);
}

function recordVisit(d) {
  tab('visits', VISIT_HEADERS).appendRow([
    new Date(), clip(d.session_id), clip(d.country), clip(d.region), clip(d.city),
    clip(d.referrer), clip(d.landing), clip(d.language), clip(d.timezone),
    clip(d.device), clip(d.browser), clip(d.os), clip(d.screen), clip(d.viewport),
    clip(d.theme), '', '', '', ''
  ]);
}

/** Fill engagement onto the existing row for this session, newest match first. */
function updateVisit(d) {
  const sh = tab('visits', VISIT_HEADERS);
  const last = sh.getLastRow();
  if (last < 2) return;
  const ids = sh.getRange(2, 2, last - 1, 1).getDisplayValues();
  for (let i = ids.length - 1; i >= 0; i--) {
    if (ids[i][0] === d.session_id) {
      sh.getRange(i + 2, 16, 1, 4).setValues([[
        clip(d.seconds), clip(d.scroll_pct), clip(d.sections), clip(d.actions)
      ]]);
      return;
    }
  }
}
```

3. Save (the disk icon).

## Step 3: deploy it

1. **Deploy → New deployment**.
2. Click the gear next to "Select type" and choose **Web app**.
3. Set:
   - **Description**: anything, e.g. `portfolio v1`
   - **Execute as**: **Me**
   - **Who has access**: **Anyone** ← must be "Anyone", not "Anyone with Google
     account", or visitors hit a login wall and nothing records
4. **Deploy**, then approve the authorisation prompts. The "Google hasn't
   verified this app" warning is expected for your own script: choose
   **Advanced → Go to (project name)**.
5. Copy the **Web app URL**. It looks like
   `https://script.google.com/macros/s/AKfy....../exec`.

## Step 4: paste the URL into the site

Open `assets/js/site.js`, find this line above the score section:

```javascript
const FORM_ENDPOINT = '';
```

and put your URL between the quotes:

```javascript
const FORM_ENDPOINT = 'https://script.google.com/macros/s/AKfy....../exec';
```

That one constant switches on **both** the note form and the visit record. While
it is empty, neither collects anything: the form falls back to a pre-filled
email, and the footer says plainly that nothing is being recorded.

Bump the `?v=` number on the `site.css` and `site.js` links in `index.html` so
GitHub Pages serves the new file, then commit and push.

## Step 5: test it

1. Open the live site. Within a second or two a row should appear in `visits`.
2. Scroll to **Now score the page**, give it a score and a short note, send.
   A row should appear in `notes`.
3. Close the tab. The `seconds`, `scroll_pct`, `sections` and `actions` columns
   on your `visits` row should fill in.

## Reading the data

**Into Excel:** File → Download → Microsoft Excel (.xlsx).

**Get told about new notes** rather than checking: Tools → Notification settings
→ Notify me when… any changes are made.

**Useful things to look at once you have some rows:**

- `sections` tells you where people actually stop. If nobody reaches
  `#evidence`, the experiments above it are too long.
- `actions` containing `cv` is the strongest single signal on the sheet.
- `scroll_pct` clustered under 30 means the hero is not doing its job.
- `referrer` tells you whether LinkedIn, email or Scholar is actually working.

## Troubleshooting

**Nothing arrives at all.**
Almost always "Who has access" is not set to **Anyone**. Redeploy and check.

**Notes arrive but visits do not.**
Check the browser console for a blocked request: some ad blockers block any
request to a URL containing analytics-shaped patterns, and some block
`ipwho.is`. The visit still records without location; if it records nothing,
the endpoint is the problem, not the geo lookup.

**You edited the script and nothing changed.**
Apps Script serves the *deployed* version, not the saved one. Use **Deploy →
Manage deployments → edit (pencil) → Version: New version → Deploy**.

**You want to stop collecting.**
Set `FORM_ENDPOINT` back to `''`, or **Deploy → Manage deployments → Archive**.
Both paths degrade cleanly and the page keeps working.

## If you would rather not use Google

Both payloads are flat JSON objects with a `type` field, so any endpoint that
accepts a POST works: Formspree, Basin, a Cloudflare Worker writing to D1, or a
small Vercel function. Only the URL changes.
