# Connecting the note form to a spreadsheet

The site is static and hosted on GitHub Pages, so it has no server of its own.
To collect what people submit, the form posts to a **Google Apps Script web
app**, which appends a row to a **Google Sheet** you own. The sheet exports to
`.xlsx` whenever you want it in Excel.

No third-party form service, no account with anyone new, no monthly limit worth
worrying about, and the data sits in your own Drive rather than someone else's
database.

**Time: about ten minutes, once.**

---

## What gets collected

Only what a visitor deliberately types and submits:

| Column | Source |
|---|---|
| `submitted_at` | timestamp generated in the browser |
| `received_at` | timestamp generated by the script |
| `score` | the 1 to 6 rating, if they gave one |
| `name` | free text, optional |
| `email` | free text, optional, only if they want a reply |
| `role` | the dropdown |
| `message` | free text, optional |
| `page` | which path they submitted from |

There is no IP address, no fingerprint, no analytics and no cookie. That is
deliberate: the page tells visitors nothing is collected unless they press send,
and that claim has to stay true. If you later add tracking of any kind, change
the wording in the `note__privacy` paragraph in `index.html` at the same time.

## Step 1: create the sheet

1. Go to <https://sheets.google.com> and create a blank spreadsheet.
2. Name it something like `portfolio-notes`.
3. Leave it empty. The script writes its own header row on first use.

## Step 2: add the script

1. In that sheet, open **Extensions → Apps Script**.
2. Delete whatever is in `Code.gs` and paste this in full:

```javascript
/**
 * Receives submissions from the portfolio note form and appends one row.
 * Deploy as: Execute as = Me, Who has access = Anyone.
 */
const HEADERS = ['received_at', 'submitted_at', 'score', 'name', 'email', 'role', 'message', 'page'];

function doPost(e) {
  const lock = LockService.getScriptLock();
  lock.waitLock(20000);
  try {
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];

    if (sheet.getLastRow() === 0) {
      sheet.appendRow(HEADERS);
      sheet.getRange(1, 1, 1, HEADERS.length).setFontWeight('bold');
      sheet.setFrozenRows(1);
    }

    const d = JSON.parse(e.postData.contents);
    const clip = (v) => String(v == null ? '' : v).slice(0, 5000);

    sheet.appendRow([
      new Date(),
      clip(d.submitted_at),
      clip(d.score),
      clip(d.name),
      clip(d.email),
      clip(d.role),
      clip(d.message),
      clip(d.page)
    ]);

    return json({ ok: true });
  } catch (err) {
    return json({ ok: false, error: String(err) });
  } finally {
    lock.releaseLock();
  }
}

function doGet() {
  return json({ ok: true, note: 'This endpoint accepts POST only.' });
}

function json(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

3. Save (the disk icon).

## Step 3: deploy it

1. **Deploy → New deployment**.
2. Click the gear next to "Select type" and choose **Web app**.
3. Set:
   - **Description**: anything, e.g. `portfolio form v1`
   - **Execute as**: **Me**
   - **Who has access**: **Anyone**  ← this must be "Anyone", not "Anyone with Google account", or visitors will hit a login wall
4. **Deploy**. Google will ask you to authorise it; approve the prompts. The
   "Google hasn't verified this app" warning is expected for your own script:
   choose **Advanced → Go to (project name)**.
5. Copy the **Web app URL**. It looks like
   `https://script.google.com/macros/s/AKfy.....￼...../exec`.

## Step 4: paste the URL into the site

Open `assets/js/site.js`, find this line near the score section:

```javascript
const FORM_ENDPOINT = '';
```

and put your URL between the quotes:

```javascript
const FORM_ENDPOINT = 'https://script.google.com/macros/s/AKfy....../exec';
```

Bump the `?v=` number on the `site.js` and `site.css` links in `index.html` so
GitHub Pages serves the new file, then commit and push.

## Step 5: test it

Open the live site, scroll to **Now score the page**, give it a score and a
short message, and press send. A row should appear in the sheet within a second
or two. If it does not, see troubleshooting below.

## Getting it into Excel

In the sheet: **File → Download → Microsoft Excel (.xlsx)**.

To be told about new entries rather than checking: **Tools → Notification
settings → Notify me when… any changes are made**.

---

## Troubleshooting

**Nothing arrives, and the form says it did not go through.**
Almost always "Who has access" is not set to **Anyone**. Redeploy and check.

**You edited the script and nothing changed.**
Apps Script serves the *deployed* version, not the saved one. Use **Deploy →
Manage deployments → edit (pencil) → Version: New version → Deploy**.

**You want to stop collecting.**
Set `FORM_ENDPOINT` back to `''`, or **Deploy → Manage deployments → Archive**.
The form keeps working either way; it falls back to a pre-filled email.

## If you would rather not use Google

The form posts a flat JSON object, so any endpoint that accepts a POST works.
Drop-in alternatives, no code changes beyond the URL:

- **Formspree** (<https://formspree.io>), free tier, emails you each submission
  and exports CSV.
- **Basin** (<https://usebasin.com>), similar, with spam filtering.
- **Cloudflare Workers**, if you would rather own the whole path.

Whichever you choose, the fallback behaviour stays the same: if the endpoint is
unreachable, the visitor is handed a pre-filled `mailto:` link and nothing they
typed is lost.
